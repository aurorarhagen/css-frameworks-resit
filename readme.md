# CSS Frameworks, Bootstrap

![image](/images/screenshot-homepage-linkup.jpg)

School project from Noroff to create a social media page using Bootstrap. 

## Description

A static website for a social media page called LinkUp. It is built using Bootstrap as a CSS framework and also uses SASS. 

All pages:

- Login page
- Profile page
- Feed page

## Built With

- HTML5
- Bootstrap
- SASS

## Getting Started

### Installing

1. Clone the repo:

```bash
git clone https://github.com/aurorarhagen/css-frameworks-resit.git
```

2. Install the dependencies:

```bash
npm install
```

### Running

To run the app in dev mode, run the following commands:

```bash
npm run dev
```
